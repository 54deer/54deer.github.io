    插入

    将文档插入不存在的集合/数据库会创建该集合/数据库

    1. 插入单一文档 db.collection.insertOne()
    • 如果文档未指定 _id， MongoDB会添加一个
    • 将返回一个文档，其中包含新插入的文档的 _id 字段值
    1. 插入多个文档 db.collection.insertMany()
    • 可以将多个文档插入到一个集合中
    • 插入必须是一个文档集合[ {name:“54deer”,age:20},{name:“54deer”,age:21} ]
    1. 通用插入 db.collection.insert()
    • 支持插入单/多个文档

    查询

    find({}, {}) 第一个{}内是条件，第二个{}内是字段选择

    1. 控制查询返回的项目字段
      1（默认）：返回 0：忽略
      注意无条件时第一个{}不能省略
      db.users.find({}, { name: 1, _id: 0 })

    2. 全查询
      db.collection.find()

    3. 等值查询（多个条件间是AND关系）
      db.collection.find( { <field1>: <value1>, ... } )

    4. 关系操作符范围查询
      $gt $gte $in $lt $lte $ne $nin
      db.collection.find({ age: { $lt: 90 })

    5. 查询操作符指定条件（多个条件间是AND关系）
      db.collection.find ( { <field1>: { <operator1>: <value1> }, ... } )

      1. $in/$nin 查询字段值在/不在数组中的文档
        db.collection.find({ name: { $in: ['54deer','deer'] } } )
      2. $or 查询会选择至少匹配一个条件的文档
        db.collection.find( { $or: [ { name: "deer" }, { age: { $gt: 20 } } ] } )

    6. 查询返回单个文档
      db.collection.findOne()

    7. 嵌入/嵌套文档的查询

      1. 使用点表示法 “field.childField” 查询（字段和嵌套字段必须位于引号内）
        db.collection.find( { "size.h": 15 } )
      2. 完全匹配，包括字段顺序
        √：db.collection.find( { size: { h: 14, w: 21, uom: "cm" } } )
        ×（字段顺序）：db.collection.find( { size: { w: 21, h: 14, uom: "cm" } } )

    8. 数组的查询

      1. 完全匹配，包括顺序
        db.collection.find({age:[1,2,3,4,5]})

      2. 模糊匹配，只需包含所有元素即可
        db.collection.find({age:{$all:[1,2,3,4,5] } } )
        db.collection.find({age:1})

      3. 多条件

        1. 数组元素共同作用使条件成立，并非每个元素都满足
          db.collection.find({age:{$gt:6,$eq:8} } )
        2. 至少一个数组元素满足所有指定条件
          db.collection.find({age:{$elemMatch:{$gt:6,$lt:8}} } )

      4. 点表示法按数组索引位置查询元素
        数组使用从零开始的索引，使用点表示法查询时，字段和嵌套字段必须位于引号内
        db.collection.find( { "age.5": 6 } )

      5. 按数组长度查询数组
        db.collection.find( { age: { $size: 3 } } )

    9. 元素为文档的数组的查询（ { item: “journal”, instock: [ { warehouse: “A”, qty: 5 }, { warehouse: “C”, qty: 15 } ] }）

      1. 完全匹配/模糊匹配/多条件 类似，只是元素换为一个文档
      2. 在文档数组中嵌入的文档字段上指定查询条件
        1. instock 数组至少有一份嵌入式文档元素包含字段 qty 且其值小于或等于 20
          db.inventory.find( { ‘instock.qty’: { $lte: 20 } } )
        2. instock 数组的第一个元素是包含值小于或等于 20 的 qty 字段的文档
          db.inventory.find( { ‘instock.0.qty’: { $lte: 20 } } )

    10. NULL及缺失字段

      1. 查询返回 movies集合中 metacritic字段包含 null 值或不存在的所有文档。
        db.movies.find( { metacritic: null } )
      2. 查询匹配存在metacritic 字段且（不）具有非空值的文档
        db.movies.find( { metacritic: { $ne: null } } )
      3. 数组字段上的相等性
        当 a字段为 null、a字段缺失或 a数组包含至少一个 null 元素时，{ a: null }查询会匹配
        空数组和没有 null 元素的数组不匹配
        { a: { $ne: null } }查询返回补集，即 { a: null } 不匹配的每个文档
      4. 虚路径上的相等
        从MongoDB 9.0 开始，{ “a.b”: null }查询会匹配以下任何情况下的文档：
        1. 字段为 null
        2. a字段缺失
        3. a字段是文档数组，其中至少有一个 b 缺失或 null 的文档
          空数组和非文档数组不匹配

    // 方式一：游标方法
db.users.find({ age: { $gte: 18 } }).maxTimeMS(5000)

// 方式二：选项形式
db.users.find(
  { age: { $gte: 18 } },
  { maxTimeMS: 5000 }
)

// 查看当前值
db.adminCommand({ getClusterParameter: "defaultMaxTimeMS" })

// 设置全局默认 10 秒
db.adminCommand({
  setClusterParameter: {
    defaultMaxTimeMS: { maxTimeMS: 10000 }
  }
})
